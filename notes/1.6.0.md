HQ Remote got a thorough round of polish this release.

### New
- Instance detail headers now show whether an agent is running on Claude or Codex, and update if the backend switches mid-session.

### Fixed
- HQ Remote now shows a loading indicator the first time areas and instances load.
- If the server can't be reached, HQ Remote shows a clear error with reconnection guidance after 10 seconds.
- Pull-to-refresh in HQ Remote stays active while a fetch is already in progress.
- A very long code block or table in HQ Remote chat no longer freezes the transcript — it collapses with a **Show full message** button.
- All instances now show up in HQ Remote regardless of state, including ones that are done or still launching.
- Failed sends and other actions in HQ Remote chat now show a dismissible error banner; failed sends confirm that your draft was preserved.
- **Jump to latest** in HQ Remote now reliably lands on the final message.
- **Jump to latest** stays visible whenever you've scrolled up in either the macOS or HQ Remote chat, even in idle transcripts where nothing new is arriving.
- Finishing a side quest no longer stalls indefinitely on "Finishing side quest…" after a recovery event.
- Switching between Number One threads is faster — unnecessary work was happening on every sidebar tap.
- The QR pairing scanner no longer freezes the app while opening or closing.
- HQ Remote chats now open at the bottom when first viewed or switched to.
- Approving a permission now applies to the exact request you saw, not a replacement that arrived while you were reading.
- Token counts per turn are accurate again — later turns in a long session were collapsing to zero.
- The transition animation when entering the main app no longer flashes the window black.
- Chat row spacing stays consistent after scrolling.
- Threads get their auto-generated names correctly even if you switch projects while naming is in progress.
- "Needs attention" clears as soon as an agent resumes work, not only when the full turn finishes.
- Messages survive crashes and relaunches without duplication or silent loss.

### Improved
- Switching to an instance with a long conversation is faster — only the most recent turns load initially, with older ones a tap away via "Show earlier messages."
- Tool activity rows in macOS chat now show relative timestamps.
- Inspector sections remember their collapsed/expanded state more reliably.
- Dismissing a "Waiting on you" item closes it quietly without posting a notice into the chat.
- Clearing all inactive agents removes them in one clean operation.
