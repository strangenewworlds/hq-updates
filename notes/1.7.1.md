### New
- Images your agents create now appear right in the chat, full-size.
- Attach photos to a message with the new image button — pick several at once.

### Fixed
- Unread agent messages now remind you every 30 minutes instead of every 6 hours.
- Dragging images into chat is more reliable, and a failed image now shows an error instead of vanishing silently.
- The highlight when dragging a file into chat now uses HQ's red instead of the old orange.
- Refresh Memory now shows clear status — queued, sent, or failed — instead of appearing to succeed when it didn't.
- When an agent hits a problem, the notice now explains what happened and what to do about it.

### Improved
- Messages you send while an agent is busy show up instantly, with a clear sending, queued, or delivered status.
- HQ now runs on the newest Claude models.
