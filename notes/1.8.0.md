# HQ 1.8.0

This release makes HQ easier to diagnose, steadier on iPhone, and more reliable when agents pause, restart, or hit provider limits.

## Diagnose slow Codex sessions

- A new diagnostic in **Settings → Agents** compares HQ’s normal Codex connection with a controlled CLI canary and records where time is being spent.
- Reports are bounded, read-only, and redacted. They never include prompts, responses, credentials, environment values, or raw error output.
- HQ agents can run the same diagnostic when helping investigate a problem.

## Keep track of active agents

- Number One’s outstanding agents now appear directly beneath their thread on Mac and HQ Remote.
- The compact **N out** control expands into a live list you can use to check status or jump straight to an agent.
- Session headers now show the model actually reported by the running backend.
- Number One can safely remove finished ad-hoc agents without touching active work or unread mail.

## A more dependable HQ Remote

- Paired servers now reconnect after the device unlocks instead of requiring you to pair again when credentials were unavailable during launch.
- Transcripts hold their position through streaming, polling, image loading, and history expansion.
- HTML artifacts open in a secure native viewer, while images can be browsed in a full-screen swipeable gallery.
- Agent lists, disclosure controls, wrapped titles, and chat headers now align and animate more cleanly.
- Push notifications from the same Mac are grouped into one expandable stack.

## More resilient sessions and mail

- Mail reliably wakes agents marked Done or suspended, and HQ waits for the backend to be genuinely alive before reporting success.
- Retryable Codex failures are no longer hidden by secondary shutdown errors, and unresolved problems remain visible after relaunch.
- Model-specific Claude limits can switch the affected session to its configured fallback without abandoning the conversation.
- Fresh Number One chapters can start automatically while you’re away, with a setting to turn this off.
- Drafts, transcripts, queued work, and thread identity survive more restart and recovery scenarios.

## Live Activity reliability

- HQ Remote cleans up duplicate fleet Live Activities and chooses the newest valid one.
- Expired activity credentials are discarded precisely, allowing later activities to start normally.
- Dead agents no longer keep the fleet activity looking busy.

## Safer recovery and approvals

- Say **“rebuild HQ”** to verify a new build, replace the running app safely, relaunch it, and restore the agents that were awake.
- Agent approvals remain exact, time-limited, and single-use across safe session recovery.
- Additional safeguards protect repositories and HQ’s live data from destructive agent commands or misconfigured tests.
