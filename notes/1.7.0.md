### New
- Fleet Critters — tiny animated companions that replace agent icons in the sidebar, showing work, waiting, attention, and sleep states at a glance.
- HQ FM — an optional ambient music station that reflects what your agents are doing, with its own volume control and a new Settings > Sound page. It shifts mood through the day.
- Changelog Garden — browse past updates as a small procedural garden, opening from Goals & Milestones.
- HQ Remote can show a Live Activity on your Lock Screen and Dynamic Island with all your live agents, each as its own critter.
- HQ Remote now shows images an agent sends or creates right in the chat, with a pinch-to-zoom viewer.
- HQ Remote can send push notifications for approvals, mentions, errors, and completions.
- HQ Remote lets you attach up to 4 photos to a message.
- HQ Remote can create new Number One side conversations right from your phone.
- HQ Remote shows a "Waiting on you" queue with full context and one-tap responses.
- HQ Remote can open the full command text behind an active step.
- HQ Remote lets you choose how long it waits before asking for Face ID again.
- HQ Remote can reveal hidden projects.
- HQ Remote's agent and session lists now support pull-down search.
- Ad-hoc agents spawned from Number One now get an automatic 30-minute check-in reminder.
- You can now pick separate Claude and Codex models for Number One's main thread versus its side quests.
- An agent whose AI backend goes down can now recover onto the other backend and keep going from where it left off.
- Goals now have a "Complete Goal" action that previews exactly what will close and which agents will stop before you confirm.
- Update notifications use a calmer custom design instead of the stock system look.
- Settings lets you choose which models power adversarial reviews.

### Improved
- HQ Remote's agent list is now sorted by what needs you most — approvals and attention first, then errors, then working agents, then idle ones.
- Releases now run quietly in the background — you can keep using HQ while one is in progress.
- HQ Remote's project switcher shows how many agents are active in each project.
- HQ Remote's settings are reorganized into one clean list.
- HQ Remote now says "Queued" instead of "Sent" for a message the agent hasn't picked up yet.
- HQ Remote's project view moved the "Waiting on you" summary and server button into the toolbar to free up space.
- HQ Remote's composer, navigation, and buttons now use Apple's Liquid Glass look throughout, and expand the moment you tap them.
- HQ Remote's push alerts now lead with the agent or thread's name.
- HQ Remote's lock screen dropped two lines that just repeated what the Face ID prompt already said.
- An agent's opening message now collapses into a single line in chat instead of appearing as a full message from you.
- Long, fast-moving chats scroll more smoothly and hold their position while a response streams in.
- Claude's memory-refresh moments now show as their own quiet step in the chat instead of interrupting other activity.

### Fixed
- HQ Remote's fleet Live Activity now actually appears, instead of silently failing to show up.
- Sessions running background tests or builds now show a clear "Waiting on…" status instead of looking idle or done.
- Scheduled reprompts no longer silently skip a run if the message never actually reached the agent.
- Trying to close a session with unread messages now clearly explains why and offers the same recovery option everywhere.
- Restored sessions keep their identity across relaunches, so schedules, notifications, and messages stay attached to the right one.
- A long agent response can no longer push the message box off-screen when you interrupt it.
- Sending a message in HQ Remote no longer gets stuck showing "Queued" forever, and no longer leaves the keyboard up after you interrupt a send.
- HQ Remote's composer buttons no longer shift position when you tap into the text field.
- HQ Remote's app icon now shows up correctly instead of appearing blank.
- HQ Remote can now stop an agent from any state, including one stuck needing attention.
- HQ Remote's send button and other prominent controls are no longer nearly invisible in dark mode.
- Approving a command in "Waiting on you" no longer asks again for the exact same command, and an approval can no longer be reused to silently authorize a different one later.
- Desktop inbox icons now animate correctly, and tapping one opens the right conversation.
- Notices from HQ now use the name you set in Settings when addressing you.
- Chat transcripts no longer go blank after sending a message or lose your scroll position while a response streams in.
- Long chat transcripts, and messages with lots of line breaks, no longer stall or freeze while scrolling.
- A brief server overload is no longer mistaken for hitting your usage limit.
- Hitting a usage limit now reliably schedules a wake-up, resumes the right session, and won't duplicate or lose your queued messages.
- Messaging between agents — inbox notices, read receipts, and replies — is far more reliable, surviving crashes and restarts without going missing or duplicating.
- Finishing a side quest no longer hangs indefinitely — it now tells you exactly what's blocking it and offers a way to force it through.
- The main window can no longer disappear off-screen entirely.
- An expired Claude login now shows a clear "please log in" message instead of a generic error.
- Ad-hoc Codex sessions get an automatically generated name again.
- HQ Remote pairing keeps working even after your Mac's network address changes.
- Sleeping agent critters now rest with a gentle smile instead of a frown.
